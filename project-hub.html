אנחנו בשלב הליטוש: עוברים על המודולים אחד אחד, מתקנים ומחדדים. אחרי זה בונים את החסר, ובסוף הופכים הכול לאפליקציה אחת.

  4. אי-שוויונות כיתות ח׳–ט׳

  6. מעגל כיתה ח׳
  7. משפט פיתגורס כיתות ח׳–ט׳
  8. דמיון משולשים כיתות ח׳–ט׳
  9. חזקות ושורשים כיתות ח׳–ט׳

פתוח לבירור

  • systems.html אינו בתיקיית mathproject ואינו בגיטהאב (17 מתוך 18 מודולים). צריך לאתר אותו או לבנות מחדש.
  • משוואות מתקדמות, תת-פרק 5: הפרומפט נכתב, ולא אושר שנבנה.
  • דמיון משולשים, תת-פרק 4 נדחה בכוונה.
  • אתר חי: הפרויקט עלה ל-Vercel מהריפו Suleiman26/MathProject. נשארה הגדרה של Deployment Protection כדי שיהיה פתוח לתלמידים.

הבא: למלא את מה שחסר

  1. שאלות מילוליות: משוואות, מערכות, אחוזים, תנועה
  2. סטטיסטיקה והסתברות
  3. הוכחות גיאומטריות

הסדר הוא הצעה, לא החלטה.

אחר כך: אפליקציה אחת

מסך אחד עם כל המודולים, שלבי התקדמות בסגנון משחק, והעלאה ל-App Store.

  1. להתקין: Node.js, Xcode (כ-15GB), וחשבון Apple Developer (99$ לשנה). ההתקנה בתהליך, לפי מה שדווח.
  2. לפתוח ב-Claude Code פרויקט Expo חדש
  3. להעביר את המודולים למסכי React Native
  4. לעצב שלבים והתקדמות כמו במשחק
  5. לבנות בענן עם EAS Build ולהעלות

איך כל מודול בנוי

עקרונות שחוזרים בכל המודולים, ושכדאי לשמור עליהם גם בחדשים.

התלמיד פותר, המודול לא מראה תשובות

בכל שלב מזינים תשובה ומקבלים ✓ או ✗. אין כפתור הצגת פתרון, ואפשר לנסות שוב.

מעבר לשלב הבא רק אחרי תשובה נכונה

גם בתוך תרגיל: קודם הגורם המשותף, ורק אחר כך המשך הפתרון.

שברים מוצגים אנכית

המונה מעל קו והמכנה מתחתיו, ולא בצורה a/b.

תרגילים אקראיים שנבנים מהפתרון אחורה

כך התשובות יוצאות שלמות. היוצא מן הכלל הוא פיתגורס, שמקבל גם תשובות עשרוניות.

אין הוכחות פורמליות בשלב הזה

חפיפה ודמיון נבנו בלי הוכחות. שאלות ההוכחה מחכות לשלב מאוחר.
